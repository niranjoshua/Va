# Vaticore brand kit

Vector masters (SVG) and ready exports (PNG), traced from the approved logo sheet.
The wordmark is Inter Bold, outlined to paths, so it looks the same everywhere
without the font installed.

## Colours

| Token | Hex | Use |
| --- | --- | --- |
| Navy | `#102A43` | Wordmark "vati", symbol lines, text, dark surfaces |
| Teal | `#00B8A9` | Wordmark "core", symbol facet, accents, primary button on navy |
| Cyan | `#22D3EE` | "core" and facet on dark backgrounds, forecast line on navy |
| Mist | `#F4F7FA` | Page tint, secondary backgrounds |
| Ink black | `#181818` | App icon background only |

Text on white: navy `#102A43`, secondary `#486581`, muted `#829AB1`.
Teal is an accent, not a text colour on white (use `#00897E` if teal text is needed).

## Files

| File | Use |
| --- | --- |
| `vaticore-lockup.svg` / `.png` | Primary logo on light backgrounds |
| `vaticore-lockup-dark.svg` / `.png` | On navy or dark photos |
| `vaticore-lockup-mono.svg` / `.png` | One colour print, stamps, embossing |
| `vaticore-symbol*.svg` | The gem mark alone (light, dark, mono) |
| `vaticore-wordmark*.svg` | Wordmark without the mark |
| `vaticore-icon.svg`, `vaticore-icon-512.png` | App icon, LinkedIn and social avatars |
| `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` | Browser and home screen icons |
| `og-image.png` | Link preview card (1200 x 630) |

## Rules

- Keep clear space around the lockup of at least the height of the "a".
- Do not recolour, stretch, outline or add effects to the mark.
- Minimum lockup height 20 px on screen. Below that, use the icon.
- The symbol always sits to the left of the wordmark, centred on the lowercase letters.
- Type: Inter for headings and body, IBM Plex Mono for data labels and numbers.
